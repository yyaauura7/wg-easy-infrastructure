# Личная VPN-инфраструктура на базе WireGuard

Этот репозиторий содержит конфигурацию в формате Infrastructure as Code (IaC) для развертывания приватного и надежного VPN-сервера WireGuard с веб-панелью управления через Docker.

## 🏗 Архитектура и Стек
- **VPN-протокол:** WireGuard (быстрый, современный, работает на уровне ядра Linux).
- **Контейнеризация:** Docker и Docker Compose.
- **Веб-интерфейс:** `wg-easy` для создания клиентов и управления ими.
- **Безопасность:** Эшелонированная защита (Defense in Depth)[cite: 1]. UFW (открыты строго порты для туннеля и панели), криптографическое хэширование пароля алгоритмом `bcrypt`.
- **Сеть (Zero Trust):** Защищенный туннель для доступа к внутренним сервисам сервера (без выставления их портов в открытый интернет).
